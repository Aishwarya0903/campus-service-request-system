# API overview

`POST /auth/register`, `POST /auth/login`, `GET /users/me`; `POST/GET /tickets`, `GET/PATCH /tickets/{id}`, `POST /tickets/{id}/attachment`, `POST /tickets/{id}/escalate`; `GET /notifications`, `PATCH /notifications/{id}/read`; `GET/PUT /sla/rules`, `POST /sla/evaluate`; and `GET /analytics/overview`. FastAPI provides the authoritative interactive OpenAPI specification at `/docs`.
